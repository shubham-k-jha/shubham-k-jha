## ☀️ Physics-Informed ML for Solar Active Regions

**Python · Statistical Analysis · XGBoost · SHAP · Solar Physics**

> ML meets physical interpretation.

- Analysed **423 emerging active regions** from the Kutsenko 2019 catalogue
- Analysed **243 active regions** from the Kutsenko 2021 flare-productivity catalogue
- Built classification and regression workflows
- Performed feature-ablation experiments and repeated cross-validation
- Used SHAP, permutation importance and interaction analysis
- Investigated feature redundancy and leakage-aware forecasting

**Documented results:** CV R² = **0.9169** for the 2019 emergence-rate Gradient Boosting analysis and ROC-AUC = **0.8242** for the 2021 Phi-only flare classification.

[🔗 Explore project](https://github.com/shubham-k-jha/solar-ar-kutsenko-ml)

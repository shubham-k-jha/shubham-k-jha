I'm a **Research Data Analyst and Python Developer** with 3+ years of experience working with computational physics, scientific datasets, statistical analysis, time-series data, visualization, and reproducible Python workflows.

### Source-supported projects already documented in my portfolio

#### ☀️ Physics-Informed ML for Solar Active Regions
**Python + Statistical Analysis + XGBoost + SHAP + Solar Physics**

A research-oriented machine-learning study of emerging solar active regions, magnetic-flux emergence, and flare productivity, using published Kutsenko catalogues as a benchmark.

- Analysed 423 emerging active regions from the Kutsenko 2019 catalogue
- Analysed 243 active regions from the Kutsenko 2021 flare-productivity catalogue
- Built classification and regression workflows
- Performed feature-ablation experiments and repeated cross-validation
- Used SHAP, permutation importance, and interaction analysis
- Investigated feature redundancy and leakage-aware forecasting

[View project →](https://github.com/shubham-k-jha/solar-ar-kutsenko-ml)

#### 📈 Superstore Sales & Profitability Analysis
**SQL + Python + Power BI**

End-to-end retail analytics covering transactional cleaning, star-schema modelling, SQL business questions, profitability and discount analysis, Python visualizations, and an interactive dashboard.

[Live dashboard →](https://shubham-k-jha.github.io/superstore-analysis/) · [GitHub →](https://github.com/shubham-k-jha/superstore-analysis)

#### 🛒 E-Commerce Sales Analysis
**SQL + Python**

Transactional analytics covering data cleaning, joins, CTEs, subqueries, `GROUP BY`, `HAVING`, window functions, visualization, and documented business findings.

[View project →](https://github.com/shubham-k-jha/ecommerce-sales-analysis)

#### 🛒 End-to-End Online Retail Analytics
**Python + Pandas + PySpark + Scikit-learn + Apache Spark + Machine Learning**

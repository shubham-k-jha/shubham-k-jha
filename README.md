## Why My Background Is Different

My data journey started in **scientific research**, where data quality and reproducibility are not optional.

I've worked with approximately **40 GB of SDO/HMI/AIA solar data**, as well as **500+ GB of SDO/HMI data across 100+ active regions**.

**Validate → Explore → Model → Test → Explain → Communicate**

The domain changes.

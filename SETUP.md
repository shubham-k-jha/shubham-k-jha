# Repository notes

This repository contains the GitHub profile README and a small interactive portfolio explorer.

## Profile README

GitHub displays the root README.md on the shubham-k-jha profile. The visual header is maintained at assets/profile-hero.svg.

## Portfolio explorer

- portfolio/index.html is the interactive project browser.
- portfolio/projects.json contains the project descriptions, categories, and tools.

Serve the portfolio over HTTP (for example, through GitHub Pages or a local web server). Opening the HTML directly with file:// prevents the browser from fetching the JSON file.

## Editing projects

Update portfolio/projects.json when adding or changing explorer entries. Keep project descriptions factual, link to the correct repository, and explicitly identify synthetic or demo data.

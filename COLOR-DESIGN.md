# Color / Visual System

The profile now uses a deliberate rainbow system instead of random colored text:

| Area | Accent |
|---|---|
| Data Analytics | Blue |
| Data Science | Violet |
| SQL | Teal |
| BI | Orange |
| Python | Gold |
| Research | Indigo |
| Cloud | Cyan |
| Learning | Green |
| Games / CTA | Pink / Coral |

The design uses GitHub-supported Markdown/HTML plus image badges. GitHub supports HTML, tables, images and `<details>` in profile READMEs. It does not provide arbitrary CSS/JavaScript styling inside the README, so true animations/interactions belong on GitHub Pages.
